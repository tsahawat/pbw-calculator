## What is this application?
🫁 This is a predicted body weight and tidal volume calculator using the patient's height in cm and sex.

## 📲 How to add this application to your iPhone?
1. Open this <a href ="https://tsahawat.github.io/pbw-calculator/">link</a> in Safari.
2. Tap "**Share**" icon in the middle.
3. Choose "**Add to Home Screen**".
4. Tap "**Add**".

## 🤖 How to add this application to your Android phone?
1. Open this <a href ="https://tsahawat.github.io/pbw-calculator/">link</a> in Chrome.
2. Tap "**⠇menu**" (three dots) icon.
3. Choose "**Add to Home Screen**".
4. Tap "**Add**".
